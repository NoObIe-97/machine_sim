# Milestone 1 Plan

## Scope
Executable simulation with machine-native survival substrate.

## Includes
- Simulation engine with tick loop
- Machine units with hardware variants
- Resource grid with depletion/regrowth
- Component degradation and repair
- Power management
- Event logging
- Deterministic seeding
- CLI interface
- Test suite
- Demo output

## Excludes
- Reproduction, inheritance, teaching
- Semantic signaling, language
- Emotions, observer-level affect
- Social groups, civilization scoring
- Role-based agents, LLM agents

## Implementation Phases
1. Foundation: project structure, config, events, engine
2. Environment: resources, hazards, world grid
3. Machine units: base class, variants, decision primitives
4. Guardrails: lexical, AST, runtime validation
5. CLI + integration: commands, tests, demo
6. Polish: coverage, type hints, docs
