# Review Package Specification

For each milestone handoff, produce a review package containing:

| Item | Description |
|------|-------------|
| Commit hash | Exact commit being reviewed |
| File tree | Complete file listing |
| Commands run | Exact pip install, pytest, CLI commands |
| Test results | Full pytest output with pass/fail counts |
| Coverage report | pytest-cov terminal output |
| Guardrail output | `check` command output |
| Demo output | Sample simulation run output |
| Report path | Path to milestone report |
| Known limitations | What's not yet implemented |
